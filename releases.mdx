This page covers where to find Kyrou's release notes, how to read changelogs, and how to download a specific version if you ever need one. Whether you want to see what changed in the latest update or roll back to an earlier build, everything you need is here.

## Where to Find Releases

The official releases page lives at [https://github.com/SeiynJie/kyrou-releases/releases](https://github.com/SeiynJie/kyrou-releases/releases). Every release entry lists the version number, the date it was published, and a full changelog describing what changed — including new features, bug fixes, and any known issues.

## Understanding Version Numbers

Kyrou uses **semantic versioning** in the format `MAJOR.MINOR.PATCH`:

- **PATCH** (e.g., v0.1.4 → v0.1.5) — Bug fixes and small improvements that don't change existing functionality.
- **MINOR** (e.g., v0.1.x → v0.2.0) — New features added in a backward-compatible way. Existing workflows won't break.
- **MAJOR** (e.g., v0.x.x → v1.0.0) — Significant changes that may include breaking changes to existing behavior.

Since Kyrou is currently on `v0.x.x`, the product is in active early development. Expect frequent improvements as the software matures toward a stable v1.0 release.

## Downloading a Specific Version

You might want a specific version for testing a reproducible issue, comparing behavior across releases, or temporarily rolling back after an update causes a problem.

To download a specific version:

1. Go to the [releases page](https://github.com/SeiynJie/kyrou-releases/releases).
2. Scroll through the list and find the version you need.
3. Click on the release to expand its details.
4. Expand the **Assets** section at the bottom of the release entry.
5. Download the file that matches your operating platform.

<Warning>
  Running an older version means you won't receive the latest security patches or bug fixes. Only use an older version temporarily, and re-enable automatic updates as soon as you're done to return to a supported release.
</Warning>

## Release Channels

Kyrou currently publishes all releases to the public `kyrou-releases` channel on GitHub. Every stable release is available here, and this is the channel the auto-update system reads from when checking for a newer version. There are no separate beta or nightly channels at this time — all users receive the same stable builds.
