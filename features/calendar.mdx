## What it does

The Calendar is a unified time-grid view shared by both the Today page (single day) and the Week page (seven days). It renders tasks as time blocks positioned by `startTime`/`duration`, supports infinite horizontal scrolling through days/weeks, and lets you pinch/ctrl-scroll to zoom the hour height.

## Files tied to it

| File | Purpose |
|---|---|
| `src/features/calendar/UnifiedCalendar.tsx` | The calendar component itself. Takes a `mode: 'today' \| 'week'` prop so the same grid renders in both contexts |
| `src/features/calendar/CalendarDayColumn.tsx` | A single day's column — the hour grid plus positioned task blocks |
| `src/features/calendar/useCalendarZoom.ts` | Ctrl+wheel zoom logic; hour height persisted per-mode to `localStorage` under `kairo.cal.<mode>.hourHeight` |
| `src/features/calendar/useInfiniteDays.ts` | Infinite-scroll day windowing — keeps a rolling buffer of days (`BUFFER_DAYS = 14`) mounted around the visible range and prepends/appends as you scroll |
| `src/features/calendar/nowScroll.ts` | `centeredScrollTop()` — pure clamp math behind the **Now** button, which appears in both modes and scrolls to today's column (week mode) and vertically centers the current-time line |

## Key concepts / how it connects

- **One component, two hosts.** `TodayPage` mounts `<UnifiedCalendar mode="today" />`; `WeekPage`/`WeekPlannerView` mount it in week mode. There's no separate "day calendar" vs "week calendar" implementation to keep in sync — differences (single column vs seven, infinite horizontal scroll enabled or not) are branches inside `UnifiedCalendar` and its hooks.
- **Task blocks read from the same repository hooks** as Planner/Markdown mode (`useTasksForRange` from `src/db/repositories/taskRepository.ts`), bucketed client-side by date.
- **Parent tasks and scheduled subtasks are separate blocks — because subtasks are real task rows.** A subtask is a normal `tasks` row with `parentId` set; once it has a `startTime` it shows up in `useTasksForRange` like any other task and gets its own `↳ title` block, so drag/resize/delete act on that row directly. There is no separate projection layer or subtask calendar implementation.
- **Unscheduled subtasks have a drag-to-schedule entry point.** A subtask with no `startTime` appears nested as a chip in its parent's `TaskCard` **and** as a chip in the calendar's unscheduled header row — bucketed under its own date, else its parent's date, else today (done subtasks are excluded). Dragging either chip onto the grid is an ordinary task drag that sets the subtask's own `date`/`startTime`. Scheduling via NLP (typing a time inline) also auto-fills a missing date the same way, so a scheduled subtask always lands on a visible day.
- **Zoom and infinite scroll are separate concerns.** `useCalendarZoom` only manipulates vertical hour height; `useInfiniteDays` only manages which day columns are mounted horizontally. Both operate on the same scroll container ref.
- The `.time-slot { height: 80px }` rule in `src/index.css` is the default hour-row height that `useCalendarZoom` scales up/down from (`DEFAULT_HOUR_HEIGHT = 80`, clamped between 40 and 320).
- **Keyboard navigation.** `UnifiedCalendar` reuses the same `usePlannerKeyboardNav` hook as the planner: `Up`/`Down` move a focus ring across the day's (or, in Week mode, the active column's) scheduled `TimeBlock`s, auto-scrolling into view with the unified secondary-token ring; `Enter` opens the block's task detail; the physical Context Menu key opens its normal menu; `PageUp`/`PageDown` scroll the calendar via a new optional `onPage` callback. No separate calendar-specific nav hook was written. The first keypress now reliably focuses a block instead of sometimes requiring a second press. In Week mode, `Alt+Left`/`Alt+Right` also moves the focused block across day columns — same behavior and active-date wiring as the week planner (see [Week](/features/week)).
- **`Shift+N` scrolls to Now.** A configurable shortcut (Settings → Keyboard) fires the same "jump to current time" behavior as clicking the **Now** button — dispatched as a `kairo:scroll-to-now` event that `UnifiedCalendar` listens for. The Now button's hover title shows the shortcut hint. The same shortcut also works in the planner list views now (Today scrolls to the current task/section, Week scrolls to today's column) — see [Today](/features/today). It also focuses the nearest scheduled block at or after the current time (in Week mode, on today's column), so subsequent `Up`/`Down`/`Enter` continue from there instead of wherever focus previously was.
- **Unscheduled chips carry their project's colour** — a left border + tint matching `TaskCard`/`TimeBlock`'s convention, including the calendar's drag preview.
- **Priority no longer tints an unscheduled chip's title text.** On a chip with no project
  colour, priority still shows via the chip's background tint and left border, same as before —
  that was always the signal on this surface, the title-colour duplication is just gone now. On a
  chip that *does* have a project colour, the project's inline tint and left border already
  overrode both, so priority now has no visual signal on those chips at all.
- **`Shift+Equal` / `Shift+Minus` zoom in/out**, configurable in Settings → Keyboard, stepping the hour height through the same 40–320px range as ctrl+wheel zoom. Unlike wheel zoom (which anchors on the cursor), the keyboard shortcut anchors on the centre of the visible calendar. Works in both Today and Week.
- **`D` toggles done on the focused block** — the same shortcut as the planner, so you can complete a task straight from the calendar without opening its detail sheet. See [Today](/features/today).

## Where to start editing

- Changing how a task block looks/positions -> `CalendarDayColumn.tsx`.
- Changing zoom limits or default zoom -> `useCalendarZoom.ts` (`MIN_HOUR_HEIGHT` / `MAX_HOUR_HEIGHT` / `DEFAULT_HOUR_HEIGHT`).
- Changing how many days are buffered for infinite scroll -> `useInfiniteDays.ts` (`BUFFER_DAYS`).
- Note: there is currently no dedicated component/test subfolder under `calendar/` — all four files live flat in `src/features/calendar/`.
