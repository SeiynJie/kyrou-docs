This page covers how to download and install Kyrou on all supported platforms. Whether you're on Windows, macOS, or Linux, the process is straightforward and takes only a few minutes. Follow the section that matches your operating system to get Kyrou up and running.

## System Requirements

Before installing, confirm that your system meets the following requirements:

| Requirement | Minimum |
|---|---|
| **Operating System** | Windows 10+, macOS 11+, or Linux (glibc 2.17+) |
| **RAM** | 256 MB |
| **Disk Space** | ~100 MB |
| **Internet Access** | Required for receiving automatic updates |

## Downloading Kyrou

All Kyrou releases — including the current version, **v0.1.5** — are published on the [Kyrou releases page](https://github.com/SeiynJie/kyrou-releases/releases). The releases page lists every version with download links for each supported platform. Visit the page, locate the latest release at the top, and download the file that matches your operating system.

## Installation by Platform

<Tabs>
  <Tab title="Windows">
    1. Download the **`.exe` installer** from the [releases page](https://github.com/SeiynJie/kyrou-releases/releases).
    2. Double-click the downloaded `.exe` file to launch the installer.
    3. Follow the setup wizard — accept the license agreement, choose an installation directory if prompted, and click **Install**.
    4. Once the wizard completes, click **Finish**.
    5. Launch Kyrou from the **Start Menu** or the **desktop shortcut** created during installation.
  </Tab>
  <Tab title="macOS">
    1. Download the **`.dmg` file** from the [releases page](https://github.com/SeiynJie/kyrou-releases/releases).
    2. Open the downloaded `.dmg` file — a new window appears showing the Kyrou app icon.
    3. Drag the **Kyrou** icon into the **Applications** folder.
    4. Close the `.dmg` window and eject the disk image.
    5. Launch Kyrou from your **Applications** folder or by searching for it in **Spotlight** (`⌘ Space`).
  </Tab>
  <Tab title="Linux">
    **Using the AppImage:**
    1. Download the **AppImage** from the [releases page](https://github.com/SeiynJie/kyrou-releases/releases).
    2. Open a terminal and make the file executable:
       ```bash
       chmod +x Kyrou-v0.1.5.AppImage
       ```
    3. Run the AppImage directly:
       ```bash
       ./Kyrou-v0.1.5.AppImage
       ```

    **Using a `.deb` package (Debian/Ubuntu):**
    ```bash
    sudo dpkg -i kyrou_0.1.5.deb
    ```

    **Using an `.rpm` package (Fedora/RHEL):**
    ```bash
    sudo rpm -i kyrou-0.1.5.rpm
    ```
  </Tab>
</Tabs>

## Verifying Installation

After installing, confirm that Kyrou is running correctly:

- **System tray / menu bar** — Look for the Kyrou icon in your system tray (Windows), menu bar (macOS), or notification area (Linux). Its presence confirms Kyrou is active.
- **Version number** — Open Kyrou and navigate to **Settings**. The current version number is displayed there. It should read **v0.1.5** (or a later version if an update has already been applied).

## Uninstalling Kyrou

If you ever need to remove Kyrou from your system, follow the steps for your platform:

- **Windows** — Open **Settings → Apps**, find Kyrou in the list, select it, and click **Uninstall**.
- **macOS** — Open your **Applications** folder, drag the Kyrou app to the **Trash**, and empty the Trash.
- **Linux (AppImage)** — Delete the `.AppImage` file. No system-wide changes are made by the AppImage itself.
- **Linux (`.deb`)** — Run `sudo dpkg -r kyrou` in your terminal.
- **Linux (`.rpm`)** — Run `sudo rpm -e kyrou` in your terminal.

<Note>
  If you downloaded a specific older version for testing purposes, you don't need to reinstall from scratch to get current. Simply let Kyrou's built-in update mechanism detect and apply the latest release — it will bring you up to date automatically.
</Note>
