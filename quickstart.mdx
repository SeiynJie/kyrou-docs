This guide walks you through everything you need to get Kyrou installed and automatic updates running on your system. By the end, Kyrou will be active in the background, keeping your software current without any further effort on your part.

## Prerequisites

Before you begin, make sure you have the following:

- A supported operating system — **Windows**, **macOS**, or **Linux**
- An active **internet connection** (required to download Kyrou and receive updates)
- **Administrator or user permissions** sufficient to install software on your machine

## Getting Started

<Steps>
  <Step title="Download Kyrou">
    Visit the [Kyrou releases page](https://github.com/SeiynJie/kyrou-releases/releases) and download the installer for your platform. The current version is **v0.1.5**. Select the file that matches your operating system — Windows, macOS, or Linux — and save it to a location you can easily find.
  </Step>
  <Step title="Run the Installer">
    Open the downloaded file and follow the on-screen instructions. The installer guides you through each step of the setup process, including choosing an install location and confirming permissions. The whole process typically takes less than a minute.
  </Step>
  <Step title="Launch Kyrou">
    Once installation completes, open Kyrou from your applications — via the Start Menu on Windows, your Applications folder on macOS, or your app launcher on Linux. Kyrou starts running immediately and connects to the public update channel.
  </Step>
  <Step title="Let Kyrou Update">
    With Kyrou running, you're all set. Kyrou checks for updates automatically in the background. If a newer version is available, it downloads and installs it without any action required from you. You can continue using your computer normally throughout the process.
  </Step>
</Steps>

## What Happens Next

After setup, Kyrou runs silently in the background and periodically checks the releases channel for new versions. When an update is found, Kyrou either notifies you before applying it or installs it automatically, depending on your configured settings. Either way, your software stays current with no manual steps required.

To learn more about how the update process works and how to configure update behavior, see the [Auto-Updates](/auto-updates) page.

<Tip>
  If you run into any issues during setup, visit the [Troubleshooting](/troubleshooting) page for step-by-step guidance on the most common problems.
</Tip>
