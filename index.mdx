Kyrou is an automatic update system that keeps your software current without any manual effort on your part. Once installed, Kyrou silently checks for new releases through its public releases channel — the latest version is **v0.1.5** — and applies updates seamlessly in the background. You can stay focused on your work while Kyrou ensures you always have the newest features and fixes.

## Getting Started

<Steps>
  <Step title="Download Kyrou">
    Head over to the [releases page](/releases) and download the latest version of Kyrou for your platform. The current release is **v0.1.5**.
  </Step>
  <Step title="Install Kyrou on Your System">
    Run the installer and follow the on-screen prompts to set up Kyrou on your system. Installation only takes a few minutes and requires no special configuration to get started.
  </Step>
  <Step title="Sit Back — Updates Are Automatic">
    Once Kyrou is installed, you're all set. Kyrou monitors the public releases channel and applies updates automatically in the background, so you never have to manually check for or install new versions.
  </Step>
</Steps>

  Running into an issue? Visit the [Troubleshooting](/troubleshooting) page for step-by-step guidance on resolving common problems with Kyrou.
</Tip>
