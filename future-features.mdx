## Roadmap invariants

- **Local-only remains permanent.** Kyrou works without an account today, and optional accounts must not turn local planning into a trial.
- **Sync is optional and explicit.** Desktop discovers Sync from the sidebar; mobile discovers it from the top app bar. **Settings → Sync** manages it, but first-time OAuth starts only after **Continue with Google**.
- **Native OAuth stays out of WebViews.** Planned Google sign-in uses the external system browser with PKCE-S256, callback validation, and platform secure storage.
- **Sign-out does not cross-contaminate accounts.** Local rows stay usable, pending sync data is quarantined to the origin account, and a different account requires an explicit keep/export/remove/re-home choice.
- **The thin slice is 3-5 days.** The planned vertical slice is responsive shell + Android build path + Sync entry shells, then Supabase/Google/RLS, then Dexie-first push/pull/merge, then automation/release checks.
- **Free core sync stays free.** Free local planning and basic task/project sync are not Stripe-gated.
- **Paid deletion resolves billing first.** Stripe subscriptions/customers must be cancelled or unlinked and reconciled before profile/domain rows are purged.
- **Overlay/widgets are future platform work.** PC/Android overlay/reminder work and Android widgets come after sync and platform foundations. They are not shipped in current Kyrou.
- **iOS is deferred.** Batch 20 is research/feasibility; no current release builds iOS or promises arbitrary iOS system overlays.

## Cross-cutting notes

- Batches 1-8 are completed and archived under `docs/roadmap/archive/`. Batch 9 (responsive
  accessibility) has also shipped its code and documentation — see
  `docs/roadmap/9-responsive-accessibility.md` for status detail, including the manual
  on-device/viewport verification pass that is still outstanding. The active upcoming roadmap
  starts at Batch 10.
- Dexie remains the immediate source of truth even after planned Supabase sync. UI should keep reading local repositories rather than remote tables directly.
- Basic task/project sync is planned as free core behavior. Stripe entitlements should only unlock later paid-only features.
- Android/PC ship before iOS. iOS distribution, widgets, and Live Activities need a separate feasibility decision in Batch 20.

For exact task-level detail, open the numbered file for the active batch in `docs/roadmap/`.
