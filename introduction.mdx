Kyrou is a lightweight application that keeps your software automatically up to date — no manual downloads, no version hunting, no interruptions. Once you install Kyrou, it runs quietly in the background, monitors a public releases channel, and delivers new versions to your system the moment they become available. Whether you care about staying protected with the latest security patches or simply want new features as soon as they ship, Kyrou handles the entire process for you.

## How Kyrou Works

Kyrou follows a simple, repeatable update cycle that runs entirely without your involvement:

1. **Checks the releases channel** — Kyrou periodically polls the public releases channel to see whether a new version has been published.
2. **Detects a new version** — When Kyrou finds a version newer than the one currently installed on your system, it queues an update.
3. **Downloads the update** — Kyrou fetches the new release package in the background, using your internet connection without disrupting your work.
4. **Installs seamlessly** — The update is applied automatically. Depending on your settings, Kyrou either installs silently or notifies you before applying the change.
5. **Confirms the update** — Once complete, your software is running the latest version and the cycle begins again.
