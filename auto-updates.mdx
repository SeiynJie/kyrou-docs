Automatic updates are Kyrou's core feature. The app silently monitors the public releases channel and keeps your software current without you needing to manually download or install anything. As long as Kyrou is running, it handles the entire process for you — from detecting a new release to applying it — so you're always on the latest version.

## The Update Cycle

<Steps>
  <Step title="Version Check">
    Kyrou periodically checks the releases channel and compares the latest available version against the one you currently have installed. If a newer version exists, it moves to the next step automatically.
  </Step>
  <Step title="Download">
    When a newer version is found, Kyrou downloads the update package in the background. The download runs quietly alongside your normal workflow, so you won't experience any interruption while it completes.
  </Step>
  <Step title="Install">
    Once the download finishes, Kyrou installs the update. Depending on your settings, installation may happen immediately or be deferred until the next time you launch the app.
  </Step>
  <Step title="Restart">
    Some updates require a brief restart to fully apply the changes. When that's the case, Kyrou will prompt you before restarting so you're never caught off guard.
  </Step>
</Steps>

## Update Frequency

Kyrou checks for updates automatically on startup and continues checking at regular intervals while the app is running. This means you'll typically receive updates shortly after they're published, without any action on your part.

If you'd rather not wait for the next scheduled check, you can manually trigger one at any time — see the [Manual Update Check](#manual-update-check) section below.

## Silent vs. Prompted Updates

Kyrou supports two update modes, and you can choose whichever fits your workflow best:

- **Silent updates** — Kyrou downloads and installs the update automatically, then notifies you once it's done. This is the default mode and requires no input from you.
- **Prompted updates** — Kyrou notifies you when an update is ready and asks for your approval before installing. This gives you control over exactly when updates are applied.

You can switch between these modes in the [Settings](/settings) page under **Update Settings**.

## Manual Update Check

To check for an update at any time:

1. Open Kyrou.
2. Navigate to the main menu or open **Settings**.
3. Click **Check for Updates**.

Kyrou will immediately query the releases channel and begin downloading if a newer version is available.

<Info>
  Updates are sourced from the official public releases channel at [https://github.com/SeiynJie/kyrou-releases/releases](https://github.com/SeiynJie/kyrou-releases/releases), ensuring you always receive authentic, verified builds.
</Info>

<Tip>
  Keeping auto-updates enabled is the easiest way to always have the latest security patches and features without any manual effort.
</Tip>
