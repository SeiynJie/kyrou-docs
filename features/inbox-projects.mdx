## What it does

The Inbox & Projects screen (`/inbox`) is where undated/backlog tasks and project management live together: a sortable list of tasks not yet scheduled to a date, grouped and organized by project, plus the ability to create/edit projects (name, color, emoji).

## Files tied to it

| File | Purpose |
|---|---|
| `src/app/Inbox.tsx` | Route target for `/inbox` — top-level screen composing task list by project |
| `src/app/ProjectDetail.tsx` | Modal for viewing/editing project metadata (name, color, icon, note, default flag) |

## Key concepts / how it connects
- **Projects live in `KyrouStore.projects()`** via `src/kyrou/projects.ts`, which deduplicates names case-insensitively so no two projects share a name.
- **A task's `projectId` (a uuid string)** links it to a project by id; the inbox groups/filters using that field.
- **Task rows use the shared `TaskCard` component** (see [Today](/features/today)), so right-click menu, keyboard nav, and drag-to-reorder all work consistently.
- **The page is keyboard-navigable via the shared roving-focus panel**, the same primitive used by
  Settings and the Task Detail Sheet. `CollapsibleSection` headers are a `FocusStop` group
  (`group="horizontal"`: Left collapses, Right expands), and the `TaskCard`s inside each section
  are `FocusStop`s too. `CollapsibleSection` moved off native `<details>`/`<summary>` onto a
  controlled `open` state with `hidden="until-found"` on the collapsed body, specifically to keep
  Ctrl+F find-in-page working inside a collapsed section while still being roving-nav-addressable;
  the header toggle is a real `<button>` so Enter/Space stay native.
- **The Backlog sidebar now renders on this page too**, reusing `uiStore.backlogOpen` — no new
  state was added for it.
- **A project can be marked "Default project"** — a toggle in `CreateProjectModal` when editing an
  existing project. `KyrouProjects.defaultId()` and `KyrouProjects.defaultName()` retrieve the current
  default; only one project can be default at a time. Quick Add assigns new tasks to the default project
  when no `#project` token is typed — see [Quick Add](/features/quick-add).
- **Project colour picker.** When creating or editing a project in `CreateProjectModal`, clicking the
  colour field opens a `ColorGrid` popover showing a 12×5 grid of colour swatches (60 total). Keyboard:
  arrow keys navigate 2D (clamped), Home/End jump to first/last, Enter picks, Esc closes. A footer row
  offers "Reset colour" (hotkey R) to cycle to the next free base hue. The selected colour is reflected
  in the project's card badge and tint throughout the app.
- Per-row action buttons are reachable via Tab but are not yet in a horizontal roving group —
  deferred, not yet Left/Right navigable like the rest of the page.

## Where to start editing

- Changing the inbox list/sort behavior -> `src/app/Inbox.tsx` + relevant components.
- Changing project creation/edit fields -> edit the project shape in `src/kyrou/projects.ts` and `src/kyrou/store.ts`.
- Wiring default project -> `KyrouProjects.defaultId()` in `src/kyrou/projects.ts`.
