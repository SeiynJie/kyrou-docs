Kyrou's active roadmap lives in **`docs/roadmap/`**. Treat that folder as the source of truth; this page is only a scannable public summary. Current shipped Kyrou remains local-first and account-free by default.

**2026-09-04 design port:** Kyrou's UI and data layer were rebuilt as a mechanical port of a Claude
Design app (see [Orientation](/orientation)); persistence is now a single `localStorage` record,
not Dexie/IndexedDB. Roadmap items below that assume the old Dexie-first sync engine (12, 14a) now
need a fresh storage design before implementation, not a resumption of the pre-port plan.

The current sequence is release-first: make sync reliable, gather real feedback from prospective PMF users and the ICP, then monetize only after the retention loop is credible.

## Roadmap Invariants

- **Local-only remains permanent.** Kyrou works without an account today, and optional accounts must not turn local planning into a trial.
- **Sync is optional and explicit.** Desktop discovers Sync from the sidebar; mobile discovers it from the top app bar. Settings -> Sync manages it, but first-time OAuth starts only after Continue with Google.
- **Free local core stays free.** Local planning and recurring tasks are free; sync has a 30-day trial and then belongs to Kyrou Pro.
- **Kyrou Pro is priced plainly.** The planned Pro tier is $5/month for reliable ongoing sync and service-backed power features.
- **Deferred platform ideas stay deferred.** Older platform/distribution work, focus tracking, overlays, Android widgets, and iOS follow-up live in `docs/deferred-roadmap/`.
- **Feedback steers polish.** UI improvements come after release feedback, not before the learning loop.

For exact task-level detail, open the numbered file for the active item in `docs/roadmap/`.
